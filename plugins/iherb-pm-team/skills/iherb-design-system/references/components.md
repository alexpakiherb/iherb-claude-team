# iCL Component Inventory

Full list of components available in the iHerb Component Library (iCL) Figma file. Use this as a reference when building pages — check if a component already exists before creating custom UI.

## Buttons & CTAs

| Component | Variants |
|---|---|
| Filled Button | desktop/mobile, large/small, general/info, all states |
| Plain Button | desktop/mobile, large/small, light/dark theme, all states |
| Icon Button | various icon types |
| CTA | primary and secondary call-to-action patterns |
